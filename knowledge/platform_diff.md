# platform_diff: GBA版とSwitch版の差異

## 基本情報

- Switch版発売日: 2026年2月27日 (eShop個別販売、NSO専用タイトルではない)
- Switch版ACE初確認: 2026年2月28日頃 (デテロニー氏がメールバグ成功を報告)
- ACE手法拡散: 2026年3月初旬 (アダン氏ら拡散)
- エミュレータ: Sloop (Nintendo内製GBAエミュレータ)

## 比較

| 項目 | GBA版 | Switch版 |
|------|-------|----------|
| ACE可否 | 可 | 可 (2026年2月28日確認) |
| 手法 | メールバグ→つかむ/いれかえACE | 同じ |
| ROM種別 | オリジナル | 新ビルド (大幅改変、Rev1ベース) |
| メモリアドレス | オリジナルEWRAMレイアウト | シフトあり (個別対応が必要) |
| GBA用コードの互換性 | - | そのまま動作しない。セーブデータ破損リスク |
| 実行環境 | ネイティブハードウェア | Sloopエミュレータ |
| E-Sh4rk Code Generator対応 | 対応 | 非日本語版のみ対応 (日本語Switchは選択肢あるがコード未実装) |
| CPU動作モード | ARMv4 (ARM7TDMI) | ARMv5 (再コンパイル) |
| STRH/STRB動作 | 正常 | 誤アドレスに書き込む場合あり (要調整) |
| GBA BIOS | 外部/エミュレート | 内蔵 (BIOS回避策不要) |
| Hex Writer | 確立済み (非日本語版) | 未確立 (全言語) |

## Switch版ROMの変更点 (GBA版との差分)

1. 新規ビルドROM: オリジナルの単純移植ではなく、新リビジョンマーカーとビルド日文字列を持つ
2. ほえるバグ修正: 徘徊伝説(ライコウ・エンテイ)がほえるで永久消滅するバグを修正
3. イベントアイテム自動配布: 殿堂入り後にしんぴのチケット(ルギア・ホウオウ)とオーロラチケット(デオキシス)がバッグに入る
4. 名前フィルター追加: 不適切語のフィルタリング機能を内蔵 (ボックス名への影響は未確認)
5. Sloopエミュレータ依存: 外部エミュレータでは「unimplemented syscall」警告が発生
6. メモリアドレスのシフト: ROM改変に伴い各種アドレスが変動

## アドレスシフトの詳細 (非日本語版、Theocatic氏Gistより)

| gPlayerParty付近 | 0x0202402C | 0x02024028 | -4 |
| gPokemonStorage関連 | 0x02024284 | 0x02024280 (推定) | -4 |
| IWRAM領域 | 0x03001CE0 | 0x03001CDC | -4 |
| IWRAM領域2 | 0x020270C0 | 0x020270BC | -4 |

### Switch版で動作しないコードの分類 (pomeg-letterbombers FAQ)

1. **ROM関数呼び出し**: 殿堂入り、PID/TID変更等 → ROM再コンパイルでアドレス変更
2. **静的RAMアドレス参照**: RNGシード、カスタムスクリプト、パーティ操作 → アドレスシフト
3. **GBA固有動作依存**: Switchエミュレータが再現しない挙動 → STRH/STRB問題
4. **名前フィルター**: Nintendo語フィルタでブロックされるBox名 → 別の文字列で回避必要

### Switch版Box名入力の注意事項

- **Box4, Box8, Box12の末尾3文字にスペースを入れない** → 空にしてBox名を早期確定
- Exit Codeの調整が必要（box_name_coding.md参照）

## 日本語版ボックス名の差分

0xFFC9セットアップのBox4:
- GBA版: `ア Ｂ ぢ い い Ｎ`
- Switch版: `ア ／ ぢ い い Ｎ` (リスト記号 Ｂ→／ に変更)

## GBA用コードがSwitchで動かない理由

- Switch版ROMはGBA版から大幅改変された新ビルド
- メモリレイアウトのアドレスがシフト → ハードコードアドレスが無効化
- GBA用コードをSwitch上で使うとセーブデータ破損の可能性

## Switch版でACEが動作する理由

SloopエミュレータがオリジナルGBA動作を忠実にエミュレート → メモリ非同期化を利用するメールバグが同様に機能。

## 運用ルール

- GBA版コードをSwitch版にそのまま適用禁止
- 各プラットフォーム向け検証済みコードを使用
- アドレス対応表を必ず確認
- ぞの氏の便利コード集はGBA実機版専用 (Switch版未対応を明記)
