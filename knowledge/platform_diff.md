# platform_diff: GBA版とSwitch版の差異

## 比較

| 項目 | GBA版 | Switch版 |
|------|-------|----------|
| ACE可否 | 可 | 可 (2026年3月確認) |
| 手法 | メールバグ→つかむ/いれかえACE | 同じ |
| メモリアドレス | オリジナルEWRAMレイアウト | 異なる (ROM変更あり) |
| GBA用コードの互換性 | - | そのまま動作しない。データ破損リスクあり |
| 実行環境 | ネイティブハードウェア | NSO GBAエミュレータ |

## GBA用コードがSwitchで動かない理由

- NSO版はオリジナルROMに軽微な変更あり
- メモリレイアウトのアドレスがシフト → ハードコードアドレスが無効化
- GBA用コードをSwitch上で使うとセーブデータ破損の可能性

## Switch版でACEが動作する理由

NSOがオリジナルGBA動作を忠実にエミュレート → メモリ非同期化を利用するメールバグが同様に機能。

## 運用ルール

- GBA版コードをSwitch版にそのまま適用禁止
- 各プラットフォーム向け検証済みコードを使用
- アドレス対応表を必ず確認
